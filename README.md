# Even Steven — Pirate Clicker

Учебный проект по организации взаимодействия компонентов приложения на Unity.
Игра-кликер в пиратской тематике: игрок определяет чётность случайного числа за ограниченное время.

## 📋 Что реализовано

- Начало и завершение игровой сессии (таймер — 30 секунд)
- Генерация случайного числа и его отображение на «бумажке» в клюве попугая
- Приём и обработка ответов пользователя: «Чётное» — правая рука, «Нечётное» — левая
- Подсчёт и вывод на экран верных и неверных ответов:
  верный ответ — сундук с сокровищами, неверный — пробоина
- Звуковое сопровождение: отдельная музыка для меню и для игрового экрана,
  звуковые эффекты на ответы
- Пиратское оформление: фон, шрифты, манера подачи

## 🏗️ Архитектура

Проект построен на разделении ответственности между компонентами:

| Скрипт | Ответственность |
|--------|-----------------|
| `NumberParity` | Генерирует случайное число, принимает и обрабатывает ответы |
| `NumberParityView` | Отображает сгенерированное число |
| `AnswerTracker` | Подсчитывает количество верных и неверных ответов |
| `AnswerTrackerView` | Отображает счётчики на экране |

Такое разделение позволяет менять логику и отображение независимо друг от друга.

## 🛠️ Технологии

- **Unity 2022.3.62f3**
- C#
- UI System: Canvas, Button, Text
- Audio System: AudioSource, AudioClip

## 🎮 Как играть

1. Нажми «Старт» — начинается сессия на 30 секунд.
2. Попугай приносит бумажку со случайным числом.
3. Определи чётность: **правая рука** — чётное, **левая рука** — нечётное.
4. В правом углу экрана обновляются счётчики:
   сундук с сокровищами — верный ответ, пробоина — неверный.
5. Когда время выходит — сессия завершается.

## 📁 Структура проекта

- `Assets/Scenes/` — сцены
- `Assets/Scripts/` — скрипты логики и отображения
- `Assets/Sprites/` — графика (пиратские ассеты, руки, попугай, сундук, пробоина)
- `Assets/Audio/` — музыка и звуковые эффекты
- `Assets/Fonts/` — шрифты

## 🚀 Как запустить

1. Открой проект в Unity Hub (2022.3.62f3).
2. Открой сцену `MainScene`.
3. Нажми **Play**.
